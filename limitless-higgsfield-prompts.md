# Limitless Performance – Higgsfield-Prompts für die Scroll-Filme

Für die Website: allrich-webdesign.com/limitless/ (Ordner `limitless/` im Repo)

**Warum ich das nicht selbst machen konnte:** Das Higgsfield-Konto zeigt 0 Credits und hat keine unbegrenzten Generierungen. Sobald Credits drauf sind, kann ich es auch selbst machen. Sag einfach Bescheid.

## So gehst du vor

1. In Higgsfield (oder per Claude-Chat mit Higgsfield-Verbindung) **Seedance 2.5** wählen, Modus **Omni Reference**.
2. Die Fotos unten **per Link importieren** (die Links sind seine Original-Fotos in 1920 px).
   - Das erste Foto als **Start-Bild (start_image)**, die übrigen als **Referenzbilder (image_references)**, damit das Auto exakt gleich bleibt.
3. Einstellungen: **1080p**, **10 Sekunden**, **ohne Ton** (generate_audio aus), Bitrate **high**.
4. Jeden Film **zweimal** erzeugen: einmal **16:9** (Laptop/iPad) und einmal **9:16** (Handy).
5. Mir die fertigen Videos schicken (Link oder Datei). Ich mache daraus die Bildfolgen und baue sie ein. Auf der Seite muss sonst nichts geändert werden.

**Wichtig für Scroll-Filme:** eine einzige durchgehende Einstellung ohne Schnitt, ruhige, gleichmäßige Kamerabewegung, keine Schrift, keine Menschen, keine Logos, die sich verändern. Das Kennzeichen „LIMITLESS“ soll lesbar bleiben.
